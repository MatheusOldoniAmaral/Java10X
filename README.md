# Java10x

Repositório com os exercícios, desafios e experimentos práticos que venho desenvolvendo durante o curso **Java10x**, como parte da minha jornada de aprendizado em Java, Programação Orientada a Objetos e estruturas de dados.

## Organização

- **NivelBasico** — fundamentos da linguagem: variáveis, tipos de dados, arrays, loops, condicionais e estruturas de controle.
- **NivelIntermediario** — Programação Orientada a Objetos (POO): classes, objetos, encapsulamento, herança, polimorfismo, abstração, interfaces e desafios práticos.
- **NivelAvancado** — Collections Framework, Generics, estruturas de dados, análise de complexidade de algoritmos (Big O) e experimentos práticos com desempenho de coleções.

## Objetivo

Consolidar os fundamentos de Java por meio da prática, desenvolvendo raciocínio lógico, compreensão das estruturas de dados e boas práticas de programação, com foco na evolução para o desenvolvimento Back-end.
